## What changed

| File | Change |
|---|---|
| `backend/app/domain/authorization/permissions.py` | `Permission` 20 → 54 values (the 34 ADR-004 "new" verbs); added `ALL_PERMISSIONS`, `READ_ONLY_PERMISSIONS`; `VIEWER_PERMISSIONS` is now the read-only set |
| `backend/app/domain/authorization/policies.py` | `ROLE_GRANTS` for the five ADR roles, built from named subtraction sets (`_ADMIN_ONLY`, `_OFFICER_ONLY`, `_MEMBER_WRITE`); `default_policy()` wires them beside the `operator`/`viewer` demo aliases |

Design notes worth keeping: the team-lead grant is denied every `*:manage` verb, so a
scope-evaluation bug in P1-04 cannot widen it; no production role holds `demo:*`; `read_only`
is "every `*:read` except `audit:read`, `agents:read`, `delegations:read`" because those
three expose authority rather than operational content.
