## Change

One method, `backend/tests/doubles.py` (8 insertions):

```python
def purge(self) -> int:
    """Mirror the real adapter: drop every message, report the count removed."""
    if not self._reachable:
        raise MailboxError("mailbox offline", status=502)
    removed = len(self._messages)
    self._messages.clear()
    return removed
```

Fail-closed when unreachable keeps `clear_demo_data`'s "skip the channel" contract
(the service catches `MailboxError`), and clearing an empty list returns `0`, so the
reset path stays idempotent.

`CalendarProvider` abstract methods.
