## Transition table

| From | To | Method |
|---|---|---|
| — | invited | `Membership.invite(...)` |
| invited | active | `accept()` |
| invited | removed | `revoke_invitation()` |
| active | suspended | `suspend()` |
| suspended | active | `reinstate()` |
| active / suspended | removed | `remove()` |
| removed | invited | `reinvite(role=...)`, then `accept()` |

Anything else, including a repeated transition, raises
`ConflictError(invalid_membership_transition)`. Only `ACTIVE` authorizes work; an
`INVITED` membership holds no authority. Removal keeps the row for audit. A change that
would leave zero active `squadron_admin` is rejected with `last_administrator`.
